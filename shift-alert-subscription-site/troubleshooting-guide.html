TROUBLESHOOTING

Find the cause before changing settings

Most problems come from an old page context, a filter that is too narrow, blocked browser permissions, or a mismatch between the signed-in account and the licence binding.

Start with this five-step check

  1. Open chrome://extensions and confirm Canada Shift Watcher is enabled.
  2. Confirm the extension card shows version 1.1.13 or later.
  3. Reload the official job-search page once after installing or updating.
  4. Open the popup and confirm monitoring is enabled and settings are saved.
  5. Temporarily use Any employment type and Anywhere in Canada to test without restrictive filters.

Licence will not activate

Copy the email and token directly from the licence email. Remove spaces accidentally added before or after either value. The purchase email and licence email must refer to the same record.

If the licence was refunded, revoked, or has reached its expiry time, activation will be rejected. If the licence is active but the Amazon account has changed, contact support to request a binding reset. Support should never ask for the Amazon password.

The page is not refreshing

Check that the current address belongs to the supported Canadian job-search page. The extension does not run on unrelated pages. Reload the tab after updating an unpacked extension because an old tab can retain an invalid extension context.

Chrome may pause background work when the computer sleeps. Keep the computer awake, keep Chrome running, and confirm that battery-saving tools are not suspending it. A page refresh and the “Expand your search” retry are separate actions, so one can occur without the other.

A visible job is not being selected

First test with all optional filters disabled. Then restore location, employment type, and shift time one at a time. This identifies which displayed value differs from the saved preference.

The official search page can continue displaying a job card after its available shifts have been taken. When the page reports that the selected job has no available shifts, the extension can return and retry while that listing remains visible. It cannot select a slot that the official system says is unavailable.

No sound or notification

  • Allow Chrome notifications in Windows notification settings.
  • Turn off Do Not Disturb while testing.
  • Check the correct audio output device and volume.
  • Keep the extension enabled and the browser open.

Chrome reports “Extension context invalidated”

This normally means the extension was reloaded or updated while the job-search tab still contained the previous script. Close or reload the affected tab. Open a fresh supported search page and enable monitoring again if needed.

Settings disappear after an update

Replacing an unpacked extension can create a new extension identity if the installation path or package changes. Record important settings before removing an old copy. Keep your purchase email and token so you can activate again when the licence remains valid.

When to contact support

Contact support when payment completed but no licence arrived, a valid licence is rejected, or an account-binding reset is needed. Include the purchase email, PayPal order reference, extension version, and the exact error message. Do not include passwords, one-time codes, or identity documents.

Availability is outside the extension’s control. A technically working extension may show no result when the official site has no matching opportunities or when another applicant takes the remaining slot first.
