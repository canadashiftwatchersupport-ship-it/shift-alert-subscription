INSTALLATION GUIDE

Install and activate the extension

Canada Shift Watcher is currently distributed as a ZIP file. Follow these steps in Chrome on a desktop or laptop computer.

On this page
  1. Download and extract
  2. Load into Chrome
  3. Activate your licence
  4. Bind your account
  5. Install an update

1. Download and extract the ZIP

  1. Use the Download extension button on the official Canada Shift Watcher website.
  2. Open your Downloads folder and locate canada-shift-watcher-extension.zip.
  3. Right-click the file, choose Extract All, and select a permanent folder.
  4. Keep that extracted folder after installation. Chrome loads the extension from it.

If you open the ZIP without extracting it, Chrome cannot load the extension correctly. The folder you select should contain manifest.json, background.js, and the other extension files.

2. Load the extension into Chrome

  1. Enter chrome://extensions in Chrome’s address bar.
  2. Turn on Developer mode using the switch near the top-right corner.
  3. Select Load unpacked.
  4. Choose the extracted extension folder, then select the folder.
  5. Pin Canada Shift Watcher from Chrome’s Extensions menu so its icon remains visible.

The extension card should appear without an error banner. If Chrome says the manifest is missing, you selected the parent folder instead of the folder containing manifest.json.

3. Activate your licence

Open the extension popup. Enter the same email address used during checkout and the licence token sent after payment. Email matching ignores capitalization and accidental spaces, but using the exact checkout email avoids confusion.

  1. Paste the purchase email into the Email field.
  2. Paste the complete token into the License token field.
  3. Select Activate licence.
  4. Wait for the settings screen to appear before closing the popup.
Keep the token private. It controls paid access and should not be posted publicly or shared with another customer.

4. Bind the Amazon account

Sign in to the supported hiring website before choosing Bind / verify Amazon account. The extension reads the signed-in account identifier and sends a protected hash to the licence server. It does not read or transmit the Amazon password.

A licence is intended for the customer account that activates it. If you replace your Amazon account, contact support from the purchase email and request an account-binding reset. After support resets it, sign into the new account and bind again.

5. Install a newer version

Download and extract the new ZIP to its own folder. On chrome://extensions, remove the old unpacked copy, choose Load unpacked, and select the new folder. Then open the popup and confirm your settings.

Your licence remains on the server and normally works with an updated copy. Keep the purchase email and token available in case Chrome clears local extension storage when the old copy is removed.

Safety checklist

  • Download only from the official website.
  • Never send a password, one-time code, or identity document to support.
  • Review the official page before taking any action.
  • Complete integrity notices, verification, and final submission manually.
